# Leveraging-Machine-Learning-for-Airline-Flight-Delay-Prediction

This repository explores the use of machine learning models to predict airline flight delays. The project investigates the performance of several models, including Logistic Regression, Random Forest, XGBoost, and a Recurrent Neural Network (LSTM).

**Data**

* **Dataset:** Data Expo 2009: Airline on time data [https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/HG7NV7]
* **Data Preprocessing:** Data preprocessing steps are included within each model file (e.g., `LogisticRegression1.py`, `XGBoost8.py`).

**Models**

* **Logistic Regression:** Implemented in `models/LogisticRegression1.py`
* **Random Forest:** Implemented in `models/RFC2.ipynb.py`
* **XGBoost:** Implemented in `models/XGBoost8.py`
* **LSTM:** Implemented in `models/rnn.py`

**Evaluation Metrics**

* Accuracy
* Precision
* Recall
* F1-score
* Confusion Matrix
